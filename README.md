## Descripcion
AquaPort — Sistema de drones acuáticos de la ECI
La Escuela Colombiana de Ingeniería necesita monitorear y gestionar el reparto de muestras, sensores y equipos entre sus zonas hídricas: embalses de investigación, canales del campus y puntos de recolección ambiental. Una flota de drones acuáticos autónomos ejecuta las misiones. Los operadores asignan las rutas, los drones navegan y el sistema registra cada evento. Este es el sistema que construirás en los tres niveles, siempre el mismo, madurando con cada evolución.
